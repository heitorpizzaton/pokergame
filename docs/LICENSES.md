# Licenses and asset registry

AGENTS.md §21. Every file under `public/assets/` must match a row of the **Asset registry**
below (an exact path, or a glob). `npm run assets:check` enforces this in CI, together with the
allowed licenses, the size budgets of AGENTS.md §26 and `gltf-validator` (zero errors).

Allowed asset licenses: `Project` (generated by this repository's own scripts), `CC0-1.0`, and
`CC-BY-4.0` (only with attribution on the "Créditos" screen). Anything else fails the check.
